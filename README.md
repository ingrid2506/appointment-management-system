# Appointment Management System

## Overview

Appointment Management System is a learning project focused on practicing frontend architecture principles.

The application allows users to create, visualize, edit, and delete appointments through a Single-Page Application (SPA) built with vanilla JavaScript.

The main goal of this project is to improve understanding of frontend architecture, software organization, and maintainable code practices without relying on frontend frameworks.

---

## Features

Current features:

* Create appointments.
* View existing appointments.
* Edit appointment information.
* Delete appointments.
* Store appointment data locally using browser localStorage.

---

## Technologies

* HTML5
* CSS3
* Vanilla JavaScript

No external frameworks or libraries are currently used.

---

## Architecture

The application follows a feature-based MVC architecture.

Main architectural decisions:

* Single-Page Application (SPA).
* Feature-based folder organization.
* Model-View-Controller (MVC) separation.
* Browser localStorage as the persistence mechanism.

## Installation and Usage

### Clone the repository

```bash
git clone https://github.com/ingrid2506 appointment-management-system.git
```

### Open the project

Navigate to the project folder:

```bash
cd appointment-management-system
```

Open the application using a local development server.

Recommended:

* VS Code Live Server extension.

The application runs entirely in the browser and does not require a backend or database setup.
