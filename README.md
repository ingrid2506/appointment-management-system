# appointment-manager
A  simple web application for managing customer appointments

## Scope

In this first version, the application will allow users to create, view, edit, and delete appointments. Appointment data will be stored locally.

The following features are out of scope for this version:
- WhatsApp or SMS reminders.
- Customer profiles and appointment history.
- User authentication (login/sign up).
- Separate accounts for business owners and customers.
- Real-time availability or scheduling.
- Online payments.

## Features
- Create appointments
- View appointments
- Edit appointments
- Delete appointments
- Store data locally
- Responsive design
