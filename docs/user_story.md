## User Story
- As a user, I want to create an appointment so that I can keep track of my meetings.
- As a user, I want to view my appointment so that I can see my sheduled meetings 
- As a user, I want to edit an appointment so that I can update my meeting information.
- As a user, I want to delete an appointment so that I can remove meetings I no longer need.
- As a user, I want to receive clear feedback when I enter invalid or valid data so that I know whether my action was successful
